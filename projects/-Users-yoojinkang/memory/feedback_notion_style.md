노션 페이지를 만들 때:
- **이모티콘 최대한 배제** (섹션 색 매핑처럼 기능적으로 꼭 필요한 경우가 아니면 쓰지 말 것)
- **내용은 핵심 위주로만** — 군더더기 빼고
- **구조는 가독성이 제일 좋게** — 명확한 위계, 스캔하기 쉬운 레이아웃

**Why:** 제이드가 깔끔하고 읽기 쉬운 노션 페이지를 선호. 이모지·장식·과잉 정보는 가독성을 떨어뜨림.

**How to apply:** 새 노션 페이지 생성·기존 페이지 정리 시 항상 적용. 단, 조성만 라벨링처럼 섹션 색 이모지가 프리미어 마커 색 매핑 기능을 하는 기존 페이지는 그 기능적 용도는 유지. 관련: [[project-seongman-ep5]], [[feedback-srt-versioning]].
