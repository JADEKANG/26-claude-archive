## 원칙
딱딱한 문어체·고맥락 한자어("진학 대신", "선택한 이유", "~의 비밀")는 지양.
그 인물이 실제 살면서 **들었거나 / 말했거나 / 생각했을 법한 문장**을 그대로 챕터명으로 옮긴다.

## 핵심 톤 기준 ⭐ — EO Korea 채널 실제 패턴
(2026-04 최근 40편 분석 기준)

### 5가지 EO 시그니처 패턴
1. **"~이유 / ~전략 / ~법 / ~구별법" 종결** — "40개 제품 말아먹고 깨달은 '진짜 되는' 아이디어 구별법"
2. **단정·선언 존댓말** ("~습니다 / ~아니에요 / ~입니다") — "중국은 기회를 스스로 걷어차고 있습니다", "한국은 좁아요"
3. **대사형 따옴표 훅** — `"제 타이밍이 올 때까지 밀어붙였어요"`
4. **선행절 상황 + 결과** (가장 자주) — "선배들이 아무도 투자하지 않았던 곳에 투자하는 의사결정법"
5. **숫자·구체 박기 필수** — 17살 / 30억 / 100억 / 1조 5천억 / 40개 / 10배

### 통합 공식
**[선행절 상황(실패·반전·대비)] + [숫자/구체성] + [EO 시그니처 종결]**
- "첫 사업 접기 직전, 새벽 2시에 바꾼 방향이 300조 시장을 열었습니다"
- "2년간 만든 제품을 전부 버리고 정반대로 간 이유"

### EO 톤 NOT
- 장면(scene) 소재 남용 ("한강 다리 위에서 떠올린 한 생각" 류) — 브이로그·다큐 톤
- 시적 수사, 감성적 형용사 ("끝내려고 걸었던", "오롯이 혼자였던")
- 업계어 (피벗, 런웨이, 아이템, 매각) — 반드시 일상어로 치환
- 한강·장소는 조용히 박는 정도만, 메인 훅은 아님

## 보조 프레임 (상황에 따라)
- **주변 반응 인용형**: "야 너 대학 안 가면 뭐 먹고 살래"
- **기대 배반형**: "대학 아니고 고시원"
- **자조·셀프디스**: "이상한 학교 갔다는 소리 들으며"
- **도발 질문**: "대학 꼭 가야 돼요?"
- **반전 단정**: "대학 안 간 게 신의 한 수였다"

## 자가 점검 3문항
- 친구한테 말할 때 이렇게 말할까? (No → 문어체)
- 누가 말하는지 그림이 그려지나? (No → 캐릭터 없음)
- 같은 상황 겪은 2030이 찔릴까? (No → 자기 얘기 아님)

## 피해야 할 표현
- "~한 이유", "~의 비밀", "~에 대하여" (문어 종결)
- "진학", "결단", "선택지" (한자어 고맥락)
- "~을 통해 배운 것" (교훈체)
- 무색 동사 "~하다", "~되다" → 톤 박힌 종결 "~하더라", "~됐다"

**Why:** 유주원 대표 인터뷰("대학 진학 대신 고시원을 택한 이유")처럼 고맥락·딱딱한 제목은 한국 일상 화법과 괴리가 커서 직관적 훅이 약함. 시청자가 "이거 내 얘기" "이거 우리 엄마가 하던 말"로 느끼게 만드는 게 핵심.

**How to apply:** EO 인터뷰 영상(메인 채널·TTM 등 전 시리즈) 챕터명/썸네일 문구 제안할 때 7가지 프레임 중 인물 서사에 맞는 것을 고르고, 자가 점검 3문항을 통과시킨 후 제시. 특히 "남들 ~할 때 나는 ~" 비교 프레임은 2030 시청자에게 가장 강력하게 작동. 유주원 대표(애드쉴드) 인터뷰는 EO 메인 채널 건.
