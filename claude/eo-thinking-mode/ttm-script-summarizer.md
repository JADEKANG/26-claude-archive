# TTM Script Summarizer

인터뷰 스크립트를 TTM 편집용 섹션 브레이크다운으로 정리하고 노션 페이지에 업로드하는 워크플로우.

## 사용법

```
파일: /path/to/script.txt
노션: https://www.notion.so/eoeoeo/...

위 파일을 TTM 편집용 섹션 브레이크다운으로 정리해서 노션에 올려줘.
```

## 워크플로우

1. 스크립트 파일 읽기 (큰 파일은 offset/limit으로 나눠서)
2. 내용 큰 변화 별로 섹션 구분
3. 각 섹션을 번호 + 제목 + 타임스탬프 + 불릿 포인트로 정리
4. 노션 페이지에 replace_content로 업로드

## 노션 포맷 구조

```
> Guest: [이름] — [소속/직함]
> Topic: [인터뷰 주제]
> Total Runtime: ~Xhr Ymin

---

## 1. 섹션 제목
`00:00 – 00:00`

- 핵심 내용 불릿
- 핵심 내용 불릿

---

## 2. 섹션 제목
...
```

## 섹션 구분 기준

- 주제가 전환되는 지점 (새로운 질문 토픽)
- 데이터/사례 → 해석/의견으로 전환되는 지점
- 인터뷰이가 "또 다른 측면으로는..." 식으로 전환하는 지점
- 보통 10~15개 섹션으로 구성

## 주의사항

- 파일이 크면 Read를 offset/limit으로 나눠서 여러 번 읽기
- 노션 업로드 시 `replace_content` 커맨드 사용
- 타임스탬프는 스크립트의 `00:00 |` 형식에서 추출
