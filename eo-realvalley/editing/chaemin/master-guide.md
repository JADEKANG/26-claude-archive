## 0. 작성 원칙 (애드쉴드 학습 결과 적용)

이 가이드는 애드쉴드에서 입증된 7가지 룰을 의식적으로 적용:
1. 메타포 우선 추출 → Cold Open 1순위는 본문 후반의 강력한 비유
2. 수미상관 = 시청자 카타르시스의 1번 도구
3. 외부 인터뷰는 결정 무게/외부 검증 두 위치 (※ 이번 인터뷰는 외부 화자 없음 — 본인 단독)
4. 같은 패턴 N번 = 1차안엔 다 살리되, **임팩트 1건 + 클라이맥스 트리거 1건**만 채택
5. 컷의 기준 = 타겟 시청자에게 직접 안 닿는가
6. 엔딩 = 시청자에게 직접 호소하는 한 문장으로 끝
7. 압축비 7:1 / 19분 / 메타포 분당 1개

## 7. 인터뷰 설계도 vs 실제 인터뷰 — 발생한 차이 (편집자 주의)

| 설계도 (의도) | 실제 인터뷰 (흘러간 방향) | 편집 결정 |
|---|---|---|
| 8챕터 36질문 | AI 얘기로 먼저 들어가서 한국→미국 여정으로 회귀하는 비선형 흐름 | 비선형 그대로 살리지 말고 **편집에서 시간순 + 정서 피크 = 영상 중반 35~45%** 재배치 |
| Moneta 한 달 거주 디테일 | 거의 안 나옴, ChatGPT 이전 챗봇 일화만 짧게 | **Moneta는 한 줄 처리**, "ChatGPT 이전 보이스 챗봇 만들었던 사람"으로 캐릭터 표지로만 사용 |
| 영주권 두 번 깬 디테일 | 짧게 언급 + "더 빨리 깼을 것" 결론만 강함 | CH1 "안전을 두 번 걷어찼다"로 압축 |
| Figma 끊은 두 달 화제성 | 워크플로 디테일은 풍성하지만 "두 달" 임팩트는 낮음 | CH4에 통합, "두 달" 표현은 자막으로만 |
| 비판적 시선 (특권/일자리 파괴자/SV 거리감) | **거의 없음** — 본인이 부드럽게 풀어버림 | 컷 또는 한 줄 ("저한테 그런 질문한 사람 없었어요") |
| 변곡점 장면 (설계도엔 없음) | **작년 크리스마스 핵 위크** 강력한 단일 장면 ⭐ | **CH3 클라이맥스로 승격** |
| 테이스트/크래프트 토론 (설계도엔 없음) | 길고 강력한 도발 발언 | **CH4 핵심 메시지로 승격** |

> **편집자 핵심 결정**: 인터뷰 설계도는 인생 회고 흐름이 메인이었지만, 실제 풀스크립트의 **가장 강한 카드는 "변곡점 장면 + craft/taste 도발 + 워크플로"**. 영상도 이 축으로 재배치 권장.
