EO 관련 분석 문서는 `~/claude/`에 3개 파일로 관리:

```
~/claude/
├── EO_company_profile.md    ← 기업 정보 (회사, 철학, 브랜드, 수익, 히스토리)
├── EO_channel_analysis.md   ← 채널/콘텐츠 분석 (제작방식, IP, 인터뷰이, 경쟁환경, SWOT)
└── EO_ip_performance.md     ← IP별 성과 분석 (조회수 패턴, 편집 방향, 인터뷰이 추천)
```

EO 리서치/분석 시 이 3개 파일을 함께 업데이트할 것.
