## 성과 공식 (실제 데이터 검증 버전)

> 조회수 = **게스트 인지도 x 주제 긴급성** x 편집 밀도 x 실용성(How)

- **게스트 인지도와 주제 긴급성이 가장 강한 변수** (Po-Shen Loh 258k, Mihail Eric 233k로 입증)
- How > What > Mindset (유지, 단 게스트 변수 통제 시)
- 짧을수록 강하다: 14분(Mihail 233k) > 15분 24초(Rem 35k) > 18분(Drew 27k) — 단, Jacob(15분 45초)이 초기 인게이지먼트 최고이므로 **길이보다 밀도가 핵심**
- 공격적 편집 = 높은 성과 (압축비 6.6:1 vs 3.2:1 비교로 재확인)
- **좋아요율이 높으면 롱텀 알고리즘 부스트 신호** — Jacob 4.69%는 시리즈 최고, 추후 추이 주목

## TTM 채널 정체성

TTM은 인터뷰 채널이 아니라 **"세계 최고 전문가의 정제된 독백"** 채널.
인터뷰 형식을 채택하되, 최종 결과물은 전문가의 에세이 영상.

---

## 편집 7대 원칙

### 1. Cold Open Hook
자기소개로 시작하지 않는다. 가장 논쟁적/충격적 발언을 첫 10초에 배치.
자기소개는 hook 후 30~60초에 2~3문장으로 삽입.

### 2. 인터뷰어 투명화
인터뷰어 질문 전부 제거. 전문가 독백처럼 편집.
필요한 전환은 화면 텍스트/자막으로 처리.

### 3. 비선형 재배치
인터뷰 중간이나 후반의 강력한 발언을 앞으로 끌어옴.
시간순이 아니라 "청중 관심도 최적화 서사"로 재구성.

### 4. 반복 제거, 최고 버전만 남긴다
같은 개념의 여러 설명 중 가장 명확하고 간결한 1개만 채택.

### 5. 데이터와 스토리의 짝짓기
추상적 주장 단독으로 두지 않음. 항상 데이터 + 구체적 사례/스토리로 뒷받침.

### 6. 선언적 클로징
"감사합니다"나 "요약"으로 끝나지 않음.
대담한 선언 또는 큰 미해결 질문으로 마무리.

### 7. 게스트를 가장 똑똑하게 보이게 한다
더듬거림, 반복, filler 제거. 핵심 프레이밍 반복 강조.

## 새 소스 편집 가이드라인 (15개)

### Phase 0: 편집 전 판단
1. "이 영상의 시청자는 누구이며, 어떤 고통을 겪고 있는가?" 한 문장 정의
2. 하나의 관통 질문만 설정
3. 타겟의 크기와 긴급성 평가

### Phase 1: 오프닝 설계 (첫 30초)
4. 자기소개로 시작 금지. 충격적 데이터 > 논쟁적 주장 > 선언 순으로 오프닝 설계
5. 자기소개는 hook 후 30~60초, 2~3문장으로 압축

### Phase 2: 구조 편집
6. 토픽 5~6개 이하로 압축. 관통 질문과 무관하면 아무리 좋아도 컷
7. 비선형 재배치 적극 활용
8. 인터뷰어 질문 전부 제거
9. 반복 중 최고 버전 1개만 채택

### Phase 3: 콘텐츠 선별
10. 남길 것 우선순위: 데이터+스토리 짝꿍 > 즉시 실행 가능 조언 > 독창적 프레임워크 > 도발적 주장
11. 자를 것: 도구명 나열, 학술 크레딧, 메타 대화, 기초 설명, 홍보성 내용

### Phase 4: 클로징 설계
12. 대담한 선언 or 큰 미해결 질문으로 마무리

### Phase 5: 시리즈 차별화
13. 크로스 편집 적극 활용 (다른 에피소드 클립 30초 삽입)
14. TTM 정체성 = "전문가 독백 영상"

### Phase 6: 편집 밀도 목표
15. 채택률 목표: **4~10% (원칙)**, 단 인게이지먼트율(좋아요율 3%+, 댓글율 0.1%+) 충족 시 최대 30%까지 허용
    - 채택률이 높더라도 좋아요율이 높으면 알고리즘 친화적 콘텐츠로 판단 가능
    - 최종 길이 12~18분 유지 (핵심은 분량이 아닌 압축 밀도)

## 남길 콘텐츠 체크리스트

스크립트의 각 구간을 아래 기준으로 점수 매기기:

- [ ] 타겟 시청자의 현재 고통과 직접 연결되는가?
- [ ] 관통 질문에 답하는 내용인가?
- [ ] 데이터나 구체적 사례가 짝지어져 있는가?
- [ ] 시청자가 영상 직후 실행할 수 있는 조언인가?
- [ ] 이 게스트만이 할 수 있는 독점 정보인가?
- [ ] 다른 구간과 중복되지 않는가?

3개 이상 체크 → 반드시 남김
2개 → 고려 대상 (길이 여유 시)
1개 이하 → 컷 대상

---

## 자를 콘텐츠 체크리스트

아래 중 하나라도 해당 → 컷 우선 대상:

- [ ] 관통 질문과 무관한 사이드 토픽
- [ ] 동일 메시지의 반복 (더 좋은 버전이 다른 곳에 있음)
- [ ] 시간이 지나면 구식이 되는 도구/제품 이름 나열
- [ ] 게스트의 이력/학술 배경 상세 설명
- [ ] 인터뷰 메타 대화 ("좋은 질문이네요", "음...")
- [ ] 시청자가 이미 알 것으로 예상되는 기초 설명
- [ ] 기관/프로젝트 홍보성 발언
- [ ] 앞뒤 맥락 없이는 이해 안 되는 발언

### G1. 좋아요율을 성과의 1차 지표로 사용하라 (잠정)
조회수는 게스트 인지도에 크게 좌우된다. **좋아요율(좋아요/조회수) 3% 이상이면 콘텐츠 자체가 알고리즘 친화적**임을 의미. 초기(1~7일) 좋아요율이 높으면 장기 조회수 증가 가능성이 있다. → 7일차 좋아요율 추이로 재검증 예정.

### G2. 채택률 기준은 절대값이 아니라 인게이지먼트율과 함께 판단하라 (잠정)
채택률 29.5%(Jacob)임에도 좋아요율 4.69%로 시리즈 최고. **채택률이 높아도 남긴 내용이 즉각 실행 가능한 실용 정보라면 허용**. 채택률 4~10% 기준은 게스트 소스 품질이 낮을 때의 강제 압축 기준이지, 절대 목표값이 아님. → 장기 조회수 확인 후 채택률-성과 상관관계 재검토.

### G3. 댓글율이 높으면 주제가 공동체 내 논쟁/논의를 유발한다는 신호다 (잠정)
Jacob 댓글율 0.243% (시리즈 최고). 에이전트 관리/워크플로우 자동화 주제는 실무자들이 의견을 나누고 싶어 하는 주제. **댓글율 0.1% 이상 = 커뮤니티 반응형 콘텐츠**로 분류하고 후속 편집에 활용. → 4일차 특이치 가능성 있음, 7일차 이후 재확인.

### G4. 압축비 3.2:1은 위험 신호 — 반드시 편집 밀도를 높여라 (잠정)
Mihail 6.6:1, Drew 5.9:1 대비 Jacob 3.2:1은 절반 수준. 좋아요율은 높지만 조회수 절대값이 낮은 원인 중 하나로 추정. **소스가 풍부하지 않더라도 반복 제거, 비선형 재배치로 압축비 4:1 이상을 목표**로 설정. → 장기 조회수 성장 여부로 이 가설 검증.

### G5. 게스트 인지도가 낮을수록 오프닝 훅의 "즉각 실행 가능성"을 전면에 세워라 (잠정)
