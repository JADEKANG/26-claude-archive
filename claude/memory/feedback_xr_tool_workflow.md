Blender·Unity 작업은 백그라운드(-b, batchmode) 말고 **앱을 열어서** 실행한다 (2026-11-27 요청). Blender = 라이브 앱 + MCP, Unity = GUI 실행(`-executeMethod`, MCP 연결되면 MCP).
동작 테스트는 한 안만 밀지 말고 **여러 케이스를 만들어** 나란히 비교할 수 있게 준비 → 제이드가 보고 제일 잘 나온 걸 픽해서 그걸로 정리.

**Why:** 제이드가 직접 눈으로 확인하며 판단하고 싶어 함. 1저자로서 선택은 본인이 함.
**How to apply:** CP 준비 시 케이스 3~5개 + 한 화면 비교 영상(패널) + 수치 표. 노션은 선택 전 초안 표시. [[project_xr_research]]
