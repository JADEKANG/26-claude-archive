## 학습된 편집 7가지 룰 (애드쉴드 원본 vs 최종 영상 비교 결과)

1. **메타포 우선 추출** → Cold Open 1순위는 본문 후반의 강력한 비유
2. **수미상관 = 시청자 카타르시스의 1번 도구**
3. **외부 인터뷰는 결정 무게/외부 검증 두 위치** (애드쉴드 신용호 대표 패턴)
4. **같은 패턴 N번 = 1차안엔 다 살리되, 임팩트 1건 + 클라이맥스 트리거 1건만 채택** (애드쉴드는 4단계 시행착오 → 1단계만 살림)
5. **컷의 기준 = 타겟 시청자에게 직접 안 닿는가**
6. **엔딩 = 시청자에게 직접 호소하는 한 문장**
7. **압축비 ~7:1 / 16~19분 / 메타포 분당 1개**
