## 3. 핵심 편집 패턴 (학습 결과)

### 패턴 A. Cold Open Hook = 본문의 강력한 메시지를 미리 꺼낸다 + 수미상관

- **오프닝 1분 = CH4의 핵심**(아우토반 비유 + 비전 + 채용 철학)을 그대로 가져옴
- 같은 발언이 14:30~17:30에 본문 맥락 안에서 다시 등장 → **시청자가 "아 그래서 그게 나왔구나" 카타르시스**
- TTM 가이드 원칙 #1(Cold Open) + #3(비선형 재배치)을 동시 적용

> **앞으로 적용**: 새 게스트의 풀스크립트를 받으면 "본문에서 가장 강력한 단일 발언"을 먼저 찾고, 그걸 오프닝으로 가져온 뒤 본문에서 같은 위치에 다시 등장시키는 수미상관 구조를 1순위로 검토.

### 패턴 B. 자기소개는 hook 후 60초, 짧게 + 즉각 숫자

- "에드쉴드 = 애드블록 손실 복구" 한 문장
- 바로 핵심 숫자: 15명/150억/인당 40억
- TTM 가이드 원칙 #1 후반부(자기소개 30~60초, 2~3문장) 정확히 일치

### 패턴 C. 인터뷰어 투명화 + 외부 인터뷰로 입체감

- 인터뷰어 질문 100% 제거
- **신용호 대표 인터뷰 두 번 인서트**:
  1. CH2 멈춤 권유 시점 — "잠깐 좀 퍼즈를 걸고 싶다" / "회사는 진짜 잘 안 망해요"
  2. CH3 미국 진출 푸시 시점 — "솔직히 푸시한 거고" / "이 주일도 안 돼서 미국에 가 계셨다"
- 외부 화자가 게스트의 캐릭터를 **객관적으로 검증** = 자화자찬 톤 회피

> **앞으로 적용**: 풀스크립트에서 "투자자/공동창업자/멘토" 언급이 나오면 그분 인터뷰 추가 가능성을 즉시 체크. 마스터 가이드 피드백 단계에서 "X 인터뷰 어디서 어떻게?" 질문이 나오면 **결정의 무게가 큰 순간**과 **외부 시각 검증이 효과적인 순간** 두 곳을 후보로 제시.

### 패턴 D. 같은 패턴 압축 — 3번의 실패를 1번으로

- 마스터 가이드에서는 컬러필 → Anyfi → 데브시스터즈 → 스나이퍼 4단계 시행착오를 살리려 했음
- **실제 영상은 스나이퍼 1건만 살리고 나머지 통째로 컷**
- 이유 추정: "기술이 좋은데 디스트리뷰션 막힘" 패턴이 1번만 나와도 충분히 전달, **신용호 면담의 감정 무게를 살리려면 앞단을 비워야 함**

> **앞으로 적용**: 마스터 가이드에서 "같은 패턴의 실패 N번"을 발견하면 1차 가이드는 다 살리되, 실제 편집은 **가장 임팩트 있는 1건 + 클라이맥스 트리거 1건**만 채택하는 옵션을 함께 제시. 분량 압박 시 어디를 잘라야 할지 미리 우선순위 부여.

### 패턴 E. 클라이맥스 = 영상 중반 (35~45% 지점)

- 한강 새벽 2시 = 07:30~08:30 (영상의 39~45%)
- 마스터 가이드 ACT 3 / CH2 핵심 = "퍼즐이 맞춰지는 순간"이 정확히 그 위치
- 너무 빠르면 빌드업 부족, 너무 늦으면 결말과 겹침

### 패턴 F. 엔딩 = "거절했지만 나온 이유" + 큰 메시지

- 단순 마무리 X. 본인의 망설임 → 결단 → 사회적 메시지의 3단 구조
- "한국에 똑똑한 분들 많다, 미국 가서 도전해주길" — 시청자(타겟: 한국 창업가)에게 직접 호소
- TTM 7대 원칙 #6 "선언적 클로징" 정석 적용

### 패턴 G. 컷의 우선순위 (실제 결정 학습)

**컷된 것** (마스터 가이드에는 있지만 최종에 없음):
- 컬러필 천만 다운로드 (CH2 ①)
- Anyfi 스탠포드 팀 (CH2 ②)
- 데브시스터즈 병특 (CH2 ③)
- 친구 진서 (유학 갔던 친구)
- 게임/리그오브레전드 디테일
- 유학 고민·부모님 경제적 반대
- 첫 고객 로아와 (한국 게임 커뮤니티)
- 다크 트래픽 용어 설명
- 모트 / 선점효과 디테일 (메타포만 살림: "땅따먹기")
- 다섯명 vs 6명 구조조정 디테일 → 짧게 압축
- 사우나/콜드플런지 (마스터 가이드도 취소선)
- 정부 규제, AI 제품 통합, 단순화 철학

**살아남은 것**:
- 디미고 친구 효준 1명만
- "하지 말라는 거" 캐릭터 발언
- 부모/선생님 반대
- 새벽 4시 + 고시원 + 라면
- 신용호 면담 + 한강
- 더스틴 영입 (이름만)
- 스타벅스 / 루마 / 컨퍼런스 / 풀파티
- 3~10배 좋은 제품 + 입소문 + 땅따먹기
- 한국 vs 미국 시장 크기
- 아우토반 + 채용 철학 + AI + 비전
- "한국에 똑똑한 분들 많다"

> **공식 추출**: **컷 = 같은 메시지 중복** + **비주얼 무겁고 흐름 끊는 디테일** + **타겟 시청자에 직접 안 닿는 부분(유학·게임 취향 등)**.
> **살림 = 캐릭터 한 줄 정의 발언** + **숫자/임팩트** + **메타포(아우토반·땅따먹기·고시원·스타벅스)** + **외부 검증(신용호)**.

### 패턴 H. 메타포 우선

영상 전체에서 가장 많이 반복되는 건 **메타포**:
- 아우토반/자전거 (소수정예)
- 땅따먹기 (선점효과)
- 새벽 4시 첫차 (독기)
- 고시원/라면 (배수의 진)
- 스타벅스 아이스아메리카노 (영어 못함)
- 풀파티 (한국 정서와 충돌)
- A→B→C 채용 (인재 밀도)

**시청자가 기억하는 건 데이터가 아니라 그림이 그려지는 메타포.** 풀스크립트에서 메타포 발언을 우선 추출하는 게 1단계가 되어야 함.

## 5. 앞으로 RV 시리즈 편집 가이드 작성 시 적용할 체크리스트

### Phase 0. 풀스크립트 받자마자 1차 추출

- [ ] **메타포 발언** 모두 마킹 (시청자 기억에 남는 건 메타포)
- [ ] **캐릭터 한 줄 정의 발언** 후보 3~5개 ("하지 말라면 더 하는 아이" 같은)
- [ ] **숫자/임팩트** (인당 매출, 성장률, 시간 같은)
- [ ] **클라이맥스 후보 단일 장면** (한강 새벽 2시 같은 구체적 장면)
- [ ] **외부 인터뷰 후보 인물** (멘토/투자자/공동창업자 언급)

### Phase 1. Cold Open Hook 설계

- [ ] **본문에서 가장 강력한 단일 발언/비유** 1개 선정
- [ ] 그게 영상 후반에 본문 맥락에서 다시 나오는지 검증 (수미상관 가능성)
- [ ] 자기소개는 60초 후, 2~3문장 + 즉각 숫자

### Phase 2. 챕터 구조 — 4 챕터 + 엔딩

- [ ] 관통 테마 한 줄 정의
- [ ] 각 챕터: 벽 → 논리 → 증명 3박자
- [ ] 챕터 사이 다리 ("→ 그런데 X는?") 명시
- [ ] 클라이맥스 = 영상의 35~45% 지점

### Phase 3. 같은 패턴 압축 결정

- [ ] 시행착오가 N번이면 → 1차안엔 다 살리되, **가장 임팩트 1건 + 클라이맥스 트리거 1건**만 살리는 옵션 함께
- [ ] 컷된 시행착오의 레슨은 **다른 챕터에서 한 줄로 회수** ("컬러필 때 배운 빈 시장 선점이 여기서…")

### Phase 4. 외부 인터뷰 후보 위치

- [ ] 결정의 무게가 큰 순간 (멈춤 권유 / 결단 푸시)
- [ ] 게스트 본인이 못하는 객관 검증 (캐릭터 평가)

### Phase 5. 컷 vs 살림 우선순위

**컷 후보**:
- 같은 메시지 중복
- 흐름 끊는 디테일 (게임 취향·유학 가족사 등)
- 타겟 시청자 직접 안 닿는 부분
- 비주얼 어렵고 길어지는 설명 (다크 트래픽 같은 용어)

**살림 후보**:
- 메타포
- 캐릭터 한 줄 정의
- 핵심 숫자
- 외부 검증 (멘토/투자자 코멘트)
- 시청자 공감 포인트 (스타벅스·고시원 같은)

### Phase 6. 엔딩 설계

- [ ] 거절했던 이유 → 그럼에도 나온 이유 → 시청자 메시지 3단 구조
- [ ] 마지막 문장이 시청자에게 직접 호소 가능한가
- [ ] "안 된다는 말은 아직 아무도 증명 안 한 거다" 같은 선언

### Phase 7. 압축비 검증

- [ ] 목표 압축비 6~8:1 (TTM Mihail 6.6:1 / 애드쉴드 7:1)
- [ ] 최종 길이 12~19분
- [ ] 메타포 밀도 = 영상 분당 1개 이상

## 6. 다음 게스트에 적용할 때 — 빠른 워크플로우

1. 풀스크립트 받음 → Phase 0 1차 추출 (30분)
2. 마스터 가이드 초안 (4챕터+엔딩 + 관통 테마) 작성 (1~2시간)
3. **Cold Open 후보 + 수미상관 가능성 검증** ⭐ 이 단계가 핵심
4. 같은 패턴 압축 옵션 (1차안 vs 압축안) 함께 제시
5. 외부 인터뷰 후보 2곳 명시 (위치 + 그분에게 무엇을 물을지)
6. 컷 vs 살림 우선순위 표 (마스터 가이드에 첨부)

## 8. 결론 — RV 편집 가이드 작성 시 핵심 룰

1. **메타포 우선 추출 → Cold Open 1순위는 본문 후반의 강력한 비유**
2. **수미상관 = 시청자 카타르시스의 1번 도구**
3. **외부 인터뷰는 결정 무게/외부 검증 두 위치**
4. **같은 패턴 N번 = 1차안 살리고 압축안 옵션, 결국 1~2건만 채택**
5. **컷의 기준은 "타겟 시청자에게 직접 안 닿는가"**
6. **엔딩 = 시청자에게 직접 호소하는 한 문장으로 끝**
7. **압축비 7:1 / 19분 / 메타포 분당 1개**
