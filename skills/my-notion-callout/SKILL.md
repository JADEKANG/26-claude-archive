# my-notion-callout — 노션 메모 인사이트 콜아웃 정리

## 미션

사용자가 다큐/인터뷰 1차 편집본을 보며 적은 흩어진 메모(노션 페이지)를 받으면,
**개별 항목 나열이 아니라 그 밑에 깔린 핵심 원칙·구성 의도·인사이트**를 추출해
페이지 **맨 밑 callout 블럭**에 구조화해 넣는다.

> 핵심 철학: 메모는 "무엇을 했나"의 기록이지만, 사용자가 원하는 건 "왜/어떤 원칙으로"의 추상화다.
> 표면 항목을 받아적지 말고, 반복되는 패턴·강조 표시(★, ***, 볼드)·메타 코멘트를 단서로 원칙을 뽑아낸다.

---

## 실행 단계

### Step 0 — 도구 로드
Notion MCP 도구 스키마를 ToolSearch로 로드한다:
```
select:mcp__claude_ai_Notion__notion-fetch,mcp__claude_ai_Notion__notion-update-page
```

### Step 1 — 페이지 읽기
`notion-fetch`로 사용자가 준 URL/ID의 페이지 전체 내용을 가져온다.
- 본문 구조, 구분선(---)으로 나뉜 섹션, 토글/디테일, discussion 코멘트, 강조 표시를 모두 파악한다.
- **맨 밑에 빈 callout이 이미 있는지** 확인한다 (있으면 채우고, 없으면 새로 추가).

### Step 2 — 인사이트 추출
메모에서 다음을 찾아낸다:

1. **메타 코멘트 / 강조 표시** — `***`, `★`, `**볼드**`, "중요함", "핵심" 같은 표시가 붙은 줄은
   사용자가 직접 강조한 1순위 원칙이다. 반드시 상위로 끌어올린다.
2. **반복 패턴** — 여러 섹션에 걸쳐 반복되는 아이디어(예: "시청자가 궁금해할지 상상", "분위기 전환")는
   하나의 원칙으로 묶는다.
3. **구성 의도** — "왜 이 순서인가", "왜 여기서 전환하나" 같은 편집 논리.
4. **감정·캐릭터 설계** — 사람/관계/가치관을 어디에 어떻게 배치하는지.
5. **타임라인 처리** — 시간 순서를 따르는지/역행하는지/무시하는지.

> 5~7개의 **번호 매긴 원칙**으로 묶는 게 적정. 너무 잘게 쪼개지 말고, 표면 항목이 아니라 추상화된 원칙으로.

### Step 3 — callout 콘텐츠 작성
아래 구조로 작성한다 (노션 enhanced markdown):

```
<callout icon="📌" color="gray_bg">
**핵심 정리 — [페이지 주제] 편집 원칙 & 구성 의도**

**1. [원칙명] (★ 가장 강조되면 표시)**
[1~2문장 설명]

**2. [원칙명]**
[1~2문장 설명]

...

---
**한 줄 요약**: [전체를 관통하는 한 문장]
</callout>
```

- 사용자가 직접 강조한 원칙은 `(★ ...)` 또는 맨 위로.
- 각 원칙은 제목(볼드) + 1~2문장. 장황하지 않게.
- 맨 밑에 "한 줄 요약" 항상 포함.

### Step 4 — 페이지 업데이트
`notion-update-page`로 callout을 페이지에 반영한다.

- **빈 callout이 이미 있으면** → `update_content` 명령으로 빈 callout(`<callout ...>\n\t<empty-block/>\n</callout>`)을 채운 callout으로 교체.
- **callout이 없으면** → `insert_content` 명령 + `position: {type: "end"}`로 페이지 맨 밑에 추가.

> ⚠️ `update_content`의 `old_str`은 fetch로 받은 실제 내용과 정확히 일치해야 한다. 콜아웃 블럭 원문을 그대로 복사해 쓴다.

### Step 5 — 사용자 보고
- 어떤 원칙들로 묶었는지 한국어로 요약.
- 사용자의 편집 방법론 메모(캐릭터빌딩·후킹 심리설계·앞부분이 생명, [[feedback_editing_method]])와 연결점이 있으면 짚어준다.
- "톤/항목 추가하고 싶으면 말해달라" 한 줄.

---

## 실행 원칙

- **추상화가 핵심**: 메모 항목을 그대로 옮기지 말고, 그 밑의 원칙을 뽑는다.
- **사용자 강조 존중**: `***`/볼드/"중요" 표시된 건 반드시 상위 노출.
- **간결하게**: 원칙 5~7개, 각 1~2문장. callout이 길어지면 가치가 떨어진다.
- **한국어 출력**.
- 페이지 본문은 건드리지 않는다 — callout 블럭만 생성/수정.
- 사용자가 색/아이콘/항목 수를 지정하면 그에 맞춘다 (기본: 📌 + gray_bg).
