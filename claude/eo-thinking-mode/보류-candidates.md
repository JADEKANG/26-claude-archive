## 보류 기준

| 코드 | 의미 |
|---|---|
| `PENDING-ANGLE` | 후보 자체는 유효하나 TTM 앵글/버티컬 설계 필요 |
| `PENDING-NAME` | 이름 미확인 — 확인 후 AI 옵티미즘 재판정 필요 |
| `PENDING-VERIFY` | 심화 리서치 전 스탠스/시의성 추가 검증 필요 |
| `PENDING-TIMING` | 지금 당장보다 향후 적기가 있을 수 있음 |
