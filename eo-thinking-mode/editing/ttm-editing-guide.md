- 공격적 편집 = 높은 성과

## TTM 채널 정체성

TTM은 인터뷰 채널이 아니라 **"세계 최고 전문가의 정제된 독백"** 채널.
인터뷰 형식을 채택하되, 최종 결과물은 전문가의 에세이 영상.

## 편집 7대 원칙

### 1. Cold Open Hook
자기소개로 시작하지 않는다. 가장 논쟁적/충격적 발언을 첫 10초에 배치.
자기소개는 hook 후 30~60초에 2~3문장으로 삽입.

### 2. 인터뷰어 투명화
인터뷰어 질문 전부 제거. 전문가 독백처럼 편집.
필요한 전환은 화면 텍스트/자막으로 처리.

### 3. 비선형 재배치
인터뷰 중간이나 후반의 강력한 발언을 앞으로 끌어옴.
시간순이 아니라 "청중 관심도 최적화 서사"로 재구성.

### 4. 반복 제거, 최고 버전만 남긴다
같은 개념의 여러 설명 중 가장 명확하고 간결한 1개만 채택.

### 5. 데이터와 스토리의 짝짓기
추상적 주장 단독으로 두지 않음. 항상 데이터 + 구체적 사례/스토리로 뒷받침.

### 6. 선언적 클로징
"감사합니다"나 "요약"으로 끝나지 않음.
대담한 선언 또는 큰 미해결 질문으로 마무리.

### 7. 게스트를 가장 똑똑하게 보이게 한다
더듬거림, 반복, filler 제거. 핵심 프레이밍 반복 강조.

## 새 소스 편집 가이드라인 (15개)

### Phase 0: 편집 전 판단
1. "이 영상의 시청자는 누구이며, 어떤 고통을 겪고 있는가?" 한 문장 정의
2. 하나의 관통 질문만 설정
3. 타겟의 크기와 긴급성 평가

### Phase 1: 오프닝 설계 (첫 30초)
4. 자기소개로 시작 금지. 충격적 데이터 > 논쟁적 주장 > 선언 순으로 오프닝 설계
5. 자기소개는 hook 후 30~60초, 2~3문장으로 압축

### Phase 2: 구조 편집
6. 토픽 5~6개 이하로 압축. 관통 질문과 무관하면 아무리 좋아도 컷
7. 비선형 재배치 적극 활용
8. 인터뷰어 질문 전부 제거
9. 반복 중 최고 버전 1개만 채택

### Phase 3: 콘텐츠 선별
10. 남길 것 우선순위: 데이터+스토리 짝꿍 > 즉시 실행 가능 조언 > 독창적 프레임워크 > 도발적 주장
11. 자를 것: 도구명 나열, 학술 크레딧, 메타 대화, 기초 설명, 홍보성 내용

### Phase 4: 클로징 설계
12. 대담한 선언 or 큰 미해결 질문으로 마무리

### Phase 5: 시리즈 차별화
13. 크로스 편집 적극 활용 (다른 에피소드 클립 30초 삽입)
14. TTM 정체성 = "전문가 독백 영상"

### Phase 6: 편집 밀도 목표
15. 채택률 4~10%, 최종 길이 12~18분

## 남길 콘텐츠 체크리스트

스크립트의 각 구간을 아래 기준으로 점수 매기기:

- [ ] 타겟 시청자의 현재 고통과 직접 연결되는가?
- [ ] 관통 질문에 답하는 내용인가?
- [ ] 데이터나 구체적 사례가 짝지어져 있는가?
- [ ] 시청자가 영상 직후 실행할 수 있는 조언인가?
- [ ] 이 게스트만이 할 수 있는 독점 정보인가?
- [ ] 다른 구간과 중복되지 않는가?

3개 이상 체크 → 반드시 남김
2개 → 고려 대상 (길이 여유 시)
1개 이하 → 컷 대상

---

## 자를 콘텐츠 체크리스트

아래 중 하나라도 해당 → 컷 우선 대상:

- [ ] 관통 질문과 무관한 사이드 토픽
- [ ] 동일 메시지의 반복 (더 좋은 버전이 다른 곳에 있음)
- [ ] 시간이 지나면 구식이 되는 도구/제품 이름 나열
- [ ] 게스트의 이력/학술 배경 상세 설명
- [ ] 인터뷰 메타 대화 ("좋은 질문이네요", "음...")
- [ ] 시청자가 이미 알 것으로 예상되는 기초 설명
- [ ] 기관/프로젝트 홍보성 발언
- [ ] 앞뒤 맥락 없이는 이해 안 되는 발언

## 에피소드별 감정 아크 패턴

### 성공 패턴 (Mihail 226k)
```
공포(위기 제기) → 해법(구체적 실천) → 희망(동기부여) = 완결된 3막
```

### 중간 패턴 (Rem 34k)
```
충격(데이터) → 프레임워크(설명) → 비전(미래) = 확산형
```

### 약한 패턴 (Drew 22k)
```
주장(마인드셋) → 증거(연구) → 감동(스토리) = 분산형
```

> 교훈: "공포→해법→희망" 아크가 가장 강력. 시청자의 실존적 불안을 건드리고, 구체적 해법을 주고, 희망으로 마무리.
