유저가 아메리칸드림 1화(Sume Labs) 편집 때 직접 쓴 메모에서 드러난 편집 방법론. 거장 PD '갱갱'으로 편집 도울 때 이 원칙을 기본 적용.

**캐릭터 빌딩 먼저**: 본론 전에 인물 맥락을 충분히 깐다. "왜 왔고, 오기까지 여정, 왜 언더독인지" 등. 맥락 부족하면 시청자 납득 안 됨.

**밀도 ≠ 뭉침**: 말을 너무 짤라 붙이면 "그릭요거트 유청 분리된 것처럼 뭉쳐있는 느낌" — 이건 밀도 높은 게 아님. 호흡을 주며 재밌는 얘기 쭉 들려주고 → 비롤 → 인터뷰로 정리 → 다음 이야기. 이 교직이 핵심.

**후킹 = 시청자 심리 단계 설계**: 오프닝 30초를 "우와 → 근데? → 어 나돈데? → 봐야겠다" 식 감정 계단으로 설계. 각 단계마다 붙일 장면을 지정.

**의심 트리거는 제3자 입으로 해소**: 시청자가 "쟤네 진짜 잘해?" 의심할 지점은, 출연자 자기 입이 아니라 남의 입(리스펙 발언)으로 인정받게 처리.

**앞부분이 생명**: "시작 부분이 제일 노잼이면 거기서 다 나간다." 앞단 밀도·텐션·음악을 최우선으로 끌어올림.

**폭풍전야 연출**: 클라이맥스(데모데이 등) 직전은 긴장·베이스·타임랩스·빠른 컷으로 "밤새 얘기하는 느낌" → Fade out → 빵 터뜨림.

**raw하지만 고퀄인 소스 적극 활용**: 밥 먹는 자리 같은 날것 푸티지가 내용 재밌으면 앞단에 과감히 배치.

## 추가 원칙 (다른 에피소드 편집본 메모에서 추출, 2026-06-18) — 호기심·감정 설계형 구성
한 줄: **정보를 '설명'하지 말고, 시청자 궁금증을 따라 '유추→확인'시키며, 사람 이야기는 끝에 몰아준다.**

**① 궁금증을 설계의 축으로 (★가장 많이 반복됨)**: 시간순·정보나열이 아니라 "시청자가 다음에 뭘 궁금해할까"를 상상하고 그 질문에 답하는 순서로 따라가게 만드는 게 중심 엔진. (피칭 파트에서 특히)

**② 캐릭터는 선(先)유추 → 후(後)확인 2단 구조**: 앞에서 인물 성격 소스를 충분히 털어 시청자가 스스로 "이런 사람이겠구나" 유추하게 만든 뒤, 진짜 사실로 정답을 확인시켜줌. 직접 설명 말고 추적하게.

**③ 인간적인 면은 마지막에 몰아준다**: 아이템·팀·피칭 같은 정보는 앞·중반, 사람 냄새(가치관·관계성·원동력)는 후반·엔딩에 배치. 감정적 마무리는 가치관 대사로. ※기존 "캐릭터 빌딩 먼저"와 충돌 아님 — 맥락(왜 왔나)은 앞, 깊은 내면·가치관은 끝.

**④ 시간 순서에 얽매이지 않는다**: 기업·아이템 소개=시간순 안 중요, 관련 소스 우다다 몰아치기 / 피칭 구간=오히려 타임라인 역행으로 긴장 설계(현재→현재-1 준비→현재-0.5 가는 길).

**⑤ 분위기 전환을 구조적 장치로**: 아이템→팀, 피칭 세미나 급전환, 피칭 후기 전환 등 챕터 넘길 때마다 톤 전환으로 리듬을 만든다.

## 인터뷰·촬영 방식 원칙 (2026-07-08, 조성만·펜시브 정좌 인터뷰 + 현장 raw 정독 실측)
한 줄: **무게 있는 자백·생활질감·웃김(=IP 본질)은 정좌 인터뷰가 아니라 "가드 내려간 현장"에서 나온다.** 정좌는 설명·정리·비전선언을 줄 뿐.

**① 무게 소스 = 가드 내려간 자리.** 술자리·식사·다음날·이동·야근처럼 카메라 의식 풀린 자리에서 진짜 민낯이 나옴. (조성만 심장 ★★ 9개 전부 술자리/다음날 현장. 정좌에서 인터뷰어가 두려움 파고들어도 심장은 안 나옴.) → 촬영 설계 시 이런 자리 의도적 확보, 채굴·구성 순서는 현장부터.

**② 도전형 정좌의 역설.** 인터뷰어가 감정을 먼저 명명("~두려움 아닐까")하면 인물은 스스로 도달 못 하고 "유도된 확인"만 함. 유도된 자백은 자발적 자백보다 화면 진정성 무게가 덜함 → 열심히 팔수록 무게 옅어짐. **감정 단어는 인물이 스스로 찾게, 침묵 허용.**

**③ 질문 방향 = 추상 성찰 → 장면 재생.** "어떻게 생각하세요"(추상) 대신 "그때 뭐가 보였어요/누가 있었어요/뭐라 했어요"(장면). "질문 담아서 답해주세요"식 재진술 요구는 "완성된 척하는" 소스 양산 → 민낯과 상충, 지양.

**④ 인물 유형별 인터뷰 모드 매칭 (핵심).** 약한 인물=PD 자기노출형(상호 취약성 교환이 자백 유도 최강수, 맥주펍 사례) / 강한 확신형=관찰형 fly-on-wall(현장 자체가 정체성 증명) / 도전형=논리 검증 전용, 감정 자백엔 역효과.

※표본 확대 예정: 라앵·Arky 정좌 인터뷰 정독 추가하면 ④가 가설→패턴으로 굳음. [[project-american-dream-ip]] "인터뷰·촬영 방식 회고" 섹션 참조(기획 페이지 Retro).
