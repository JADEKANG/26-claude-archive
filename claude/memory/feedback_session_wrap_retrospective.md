세션 종료 신호(유저가 "wrap-up", "여기까지", "마무리하자" 등)가 오면, 요청받은 마무리 작업(메모리 업데이트 등) 뒤에 매번 아래 두 가지를 자동으로 덧붙인다.

1. **이번 세션 회고** — 뭐가 잘 됐고 뭐가 비효율적이었는지 구체적으로 (예: 같은 걸 여러 번 물어봤다, 확인 질문이 너무 잦았다/적었다, 특정 도구 선택이 별로였다 등).
2. **다음 세션 소통 개선 제안** — 더 효율적으로 협업하기 위한 구체적 제안 1~3개.

**Why:** 유저가 2026-09-09 세션에서 명시적으로 요청 — 매번 다시 물어보지 않아도 이게 기본 동작이길 원함.

**How to apply:** 프로젝트 무관 일반 규칙 (아메리칸 드림 IP 전용 "세션 마무리 자동 회고"와는 별개 — 그건 [확정]/[잠정] 결정사항 정리용이고, 이건 협업 방식 자체에 대한 메타 피드백). `~/.claude/CLAUDE.md`에도 일반 규칙으로 등록해둠(메모리만으론 세션 시작 시 자동 로드가 보장 안 되므로).
