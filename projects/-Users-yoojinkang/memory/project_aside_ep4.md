   - **구간 마커** = 초단문(3~16자, 전체의 ~11%): "다시 일 얘기"·"일하기"·"디자인 업무"·"촬영 세팅 얘기". 작업/잡담 구간도 타임라인을 마킹 — 내용 요약 X, "여기는 무슨 구간" 상태 표시. + **비롤 노트**: "찬희 님, 쭉 일어나는 장면 (셀프캠 비롤 있음)" 등 그림 되는 순간 마킹.
   - 하이퍼 기술 디테일(빌드·토큰·데몬 등)은 요약 가치 없음 → 구간 마커로 뭉갤 것. 단 안 쓸 긴 구간(Aside선 5곳 ~2h)은 아예 비워둠 — 100% 타일링 강박 X.
   - Arky "-30% 병합" 교훈과 종합하면: **발화 단위 과분할은 줄이되, 타임라인 커버는 구간 마커로 채운다.**

**TC:**
- 4블록 SMPTE(HH:MM:SS:FF), 시퀀스 시작 00:00:00:00 전제. raw는 소스별 0초 기준.
- 드리프트: 23.976 vs 24fps에서 `프리미어_f ≈ raw_f × 0.99897`(Arky XML 실측). 실측상 오차는 분당 sub-second라 raw 정수 TC가 이미 근접 — **진짜 TC 이슈는 드리프트가 아니라 "분할 경계"**(제이드가 병합하며 경계가 바뀜). ※Aside fps 미확인 → 소스 입수 시 첫 체크 + 2~3지점 캘리브레이션.

**운영:** 파일 버전 덮어쓰기 금지, "re" 누적 [[feedback-srt-versioning]]. 노션은 2차 검토 후 업로드 [[feedback-notion-quality]], 이모지 배제·가독성 [[feedback-notion-style]]. 대용량 전사는 4구간 병렬 서브에이전트(결과 scratchpad Write) → 갱갱 원본 대조(연속 4+ 누락·가짜TC 검사) → 정규화·검증 스크립트 → ★ 위계만 갱갱 수동 판정.
