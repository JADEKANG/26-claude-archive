# 라벨링 문체 = 제이드(PD) 관찰노트 톤

아메리칸 드림 시리즈 소스 라벨링(현장·메인 인터뷰) 작성 시 지켜야 할 문체. Aside(Ep4)에서 제이드가 2회 반려하며 확정.

**규칙:**
- **짧게.** 제이드 수기 실측 평균 42~57자(중앙 43~54), 71자+는 11~21%뿐, 25자 이하 파편도 28%. 한 라벨 = 핵심 한 방 + 부연 하나. 쉼표로 3~4절 나열 금지.
- **관찰노트 톤** — 체언·축약 종결("~중"·"~함"·"미팅 시작"·"커피 5샷 마심"). 완결 서술문·시놉시스 지양.
- **화자 실명** (효준·찬희 등). A/B/C/D 코드 금지.
- **분석 괄호태그 금지** — `(카운터빌리프)(창업 동기)(창업 철학)` 같은 내 해석 라벨 붙이지 말 것. 해석은 문장에 녹이거나 생략. ※`(웃김)`은 유지.
- 인용은 결정적 한 마디 하나만.
- **2층 구조** (Aside 수정본 실측 2026-07-21): 콘텐츠 라벨 + **초단문 구간 마커**("일하기"·"다시 일 얘기"·"일하는 brolls", 3~16자)로 작업/잡담 구간도 커버. 기술 작업 디테일은 마커로 뭉개고, 그림 되는 순간은 비롤 노트로 마킹. 무게 있는 내용은 100자까지 늘어나도 OK — 길이 규칙은 평균이지 상한 아님.
- **화자 귀속 재검**: 제이드가 화자 정정한 사례 있음(SF 불안 고백 효준→찬희). 실명 붙일 땐 원문에서 발화자 재확인.

**Why:** 제이드 라벨은 편집자가 "무슨 일 + 왜 중요한가"를 빨리 훑는 인덱스지 전사자의 시놉시스가 아님. 길고 태그 붙은 라벨은 프리미어에서 다 지워야 해서 수기 수정폭만 키움.

**How to apply:** 새 팀/새 소스 라벨링 시작 전, **"내가 만든 raw vs 제이드 수기(Arky re·Pensive 0528 등)"의 길이·문체를 정량 대조부터** 하고 그 눈금으로 깔 것. Aside에서 이걸 안 하고 감으로 깔았다가 평균 91자(2배)로 반려당함. 서브에이전트는 길고 후하게 다는 경향 → 갱갱이 길이 분포·★ keep-set 반드시 후검증.
